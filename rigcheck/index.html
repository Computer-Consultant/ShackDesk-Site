RigCheck Alpha

Serial CAT communication diagnostics using Hamlib. Verify your radio connection before it matters.

Download alpha View on GitHub

Status

RigCheck is in alpha. Builds are available for testing; there is no stable release yet.

Alpha builds expire 30 days after they are built and stop running, so testers always use current code. The expiry date is shown in the window title and in Help › About. See the download page for details.

Found a problem? Open an issue or ask in Discussions.

Features
CAT Diagnostics

Test serial communication with your radio using Hamlib's rigctl. See exactly what's working and what isn't.

Connection Verification

Confirm your rig is connected and responding before an operating session or EMCOMM activation.

Hamlib Integration

Built on the same Hamlib library used by WSJT-X, JS8Call, and other digital mode software.

Offline-First

No internet connection required. Works anywhere PortPane does.

Coming next

Environment checks — find every copy of Hamlib on the PC, check it is on the PATH, spot a running rigctld or Flrig, and check Windows Firewall rules, before any radio test runs.

Find my radio — scan the available ports and speak each radio protocol family until the rig answers, then hand you the exact settings for WSJT-X, Fldigi, or JS8Call.
